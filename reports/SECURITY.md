# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through one of the contacts listed in [`public/.well-known/security.txt`](public/.well-known/security.txt). Do not include secrets or sensitive personal data in a public issue.

The deployment security headers and content policy are maintained in [`vercel.json`](vercel.json).

## Scope

This repository contains the source for a static Astro portfolio and its deployment configuration. Reports should include the affected route or file, a short reproduction, and the expected security impact when safe to share.
